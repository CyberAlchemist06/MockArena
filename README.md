# MockArena

MockArena is a global platform for data-structures-and-algorithms assessments. It supports custom tests, coding challenges, scoring, percentiles, and leaderboards.

## Planned stack

Java 21, Spring Boot, PostgreSQL, Redis, Kafka, Docker, Kubernetes, Next.js, and TypeScript.

## Repository layout

- `docs/` — product requirements, architecture, and decisions
- `services/` — future backend services
- `infrastructure/` — future deployment and platform assets
- `scripts/` — future developer and operational scripts

See [product requirements](docs/product-requirements.md), [architecture](docs/architecture.md), and [ADR 0001](docs/adr/0001-initial-architecture.md).
